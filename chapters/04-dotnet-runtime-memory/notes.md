# Chapter 4 — .NET runtime and memory management

> **Days:** 9–10 · **Status:** Not started
>
> **Interview target:** Explain how C# code runs, diagnose growing memory usage, and tell a real leak apart from normal garbage collection.

## Topics in this chapter

1. .NET Framework vs .NET Core vs modern .NET (and the LTS/STS release cycle)
2. CLR, IL, JIT, assemblies, SDK vs runtime, and NuGet
3. Build, restore, publish and run (framework-dependent vs self-contained)
4. Stack vs heap memory
5. Garbage collection: generations 0, 1, 2 and how a GC happens
6. Large Object Heap (LOH) and allocation pressure
7. Workstation vs server GC (concept)
8. Common memory-leak causes: events, static references, caches, timers
9. Finalizers vs deterministic disposal (Dispose pattern)
10. Span<T>, ReadOnlySpan<T> and Memory<T> fundamentals
11. ArrayPool<T> and reducing allocations
12. Diagnostics tools: dotnet-counters, dotnet-trace, dotnet-dump
