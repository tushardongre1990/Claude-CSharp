# Chapter 23 — Docker, CI/CD and Kubernetes fundamentals

> **Days:** 45–46 · **Status:** Not started
>
> **Interview target:** Explain how a .NET API is built, deployed, exposed and monitored.

## Topics in this chapter

1. What containers are and why they exist
2. Images, containers and registries
3. Writing a Dockerfile for a .NET API (multi-stage builds)
4. Docker Compose: API + SQL Server + Redis
5. Configuration and secrets in containers
6. Container health checks and graceful shutdown
7. CI pipelines: restore, build, test, publish (GitHub Actions / Azure DevOps)
8. Git workflows, pull requests and code review
9. Deployment strategies: rolling, blue-green, canary, and rollback
10. Running database migrations during deployment
11. Kubernetes fundamentals: pods, deployments, services, probes, ConfigMaps and Secrets
12. API gateways with YARP or Ocelot
13. Service-to-service authentication
