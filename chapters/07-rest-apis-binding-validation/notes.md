# Chapter 7 — REST APIs, model binding and validation

> **Days:** 16–17 · **Status:** Not started
>
> **Interview target:** Design robust endpoints, explain binding and validation behavior, and handle failures consistently.

## Topics in this chapter

1. REST principles and resource naming
2. HTTP methods, idempotency and safe methods
3. HTTP status codes and when to use each
4. Model binding: route, query, header, body and form
5. What [ApiController] changes
6. IActionResult vs ActionResult<T> vs TypedResults (Minimal APIs)
7. DTOs vs entities, and mapping between them
8. JSON serialization with System.Text.Json (vs Newtonsoft.Json)
9. Validation: data annotations, IValidatableObject and custom attributes
10. Validation vs business rules
11. Custom model binders
12. Pagination, filtering and sorting
13. API versioning and backward compatibility
14. OpenAPI with Microsoft.AspNetCore.OpenApi (and Swagger UI tooling)
15. Problem Details (RFC 7807/9457) for consistent error responses
16. File uploads, request-size limits and streaming
