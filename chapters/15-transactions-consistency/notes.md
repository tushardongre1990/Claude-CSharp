# Chapter 15 — Transactions and data consistency

> **Days:** 32–33 · **Status:** Not started
>
> **Interview target:** Prevent duplicate orders, handle simultaneous inventory updates, and explain what happens when a commit succeeds but publishing an event fails.

## Topics in this chapter

1. ACID properties
2. Transaction boundaries and explicit transactions (BEGIN, COMMIT, ROLLBACK)
3. Concurrency problems: dirty reads, non-repeatable reads, phantom reads, lost updates
4. Isolation levels: Read Uncommitted, Read Committed, Repeatable Read, Serializable
5. Snapshot isolation and Read Committed Snapshot (RCSI)
6. Pessimistic vs optimistic concurrency
7. Atomic updates and unique constraints for concurrent writes
8. Transactions in EF Core (SaveChanges, BeginTransaction, TransactionScope)
9. Deadlock handling and safe retries
10. Idempotency and idempotency keys for duplicate requests
11. Distributed transactions and why to avoid them
12. The outbox pattern for reliable event publishing
