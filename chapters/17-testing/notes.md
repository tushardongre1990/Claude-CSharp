# Chapter 17 — Testing .NET applications

> **Days:** 35–36 · **Status:** Not started
>
> **Interview target:** Explain when to mock a dependency, and why passing unit tests do not guarantee that SQL works in production.

## Topics in this chapter

1. Why we test: the testing pyramid
2. Unit tests vs integration tests vs end-to-end tests
3. xUnit fundamentals: Fact, Theory, InlineData, assertions
4. Test structure: Arrange-Act-Assert, naming and fixtures
5. Test doubles: mocks, stubs and fakes (Moq / NSubstitute)
6. Testing async code and exceptions
7. Integration tests with WebApplicationFactory
8. Testing EF Core: in-memory provider vs SQLite vs real SQL Server (Testcontainers)
9. Test isolation, test data and parallel execution
10. Code coverage and its limits; avoiding brittle tests
11. Test-driven development (concept)
