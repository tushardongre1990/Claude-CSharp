# Chapter 12 — SQL fundamentals and normalization

> **Days:** 26–27 · **Status:** Not started
>
> **Interview target:** Write correct queries and explain schema design, normalization and common SQL behavior.

## Topics in this chapter

1. Tables, data types, primary keys, foreign keys and constraints
2. SELECT, INSERT, UPDATE and DELETE
3. Filtering, sorting, GROUP BY, HAVING and aggregates
4. Logical order of query execution (FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY)
5. Joins: inner, left, right, full, self and cross
6. Subqueries and correlated subqueries
7. CTEs (including recursive CTEs)
8. EXISTS vs IN vs NOT EXISTS, and NULL behavior
9. UNION vs UNION ALL, INTERSECT and EXCEPT
10. Window functions: ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD, SUM OVER
11. CROSS APPLY and OUTER APPLY
12. Views, stored procedures, functions and triggers
13. DELETE vs TRUNCATE vs DROP
14. Temporary tables vs table variables
15. Pagination with OFFSET/FETCH and TOP
16. Normalization: 1NF, 2NF and 3NF
17. Denormalization and its trade-offs
